# Revise the requirements

The independent Reviewer wrote feedback on your requirements. Read the feedback and the current document, then edit
the document in place.

- Apply every finding that the use case supports.
- When a finding contradicts the use case, leave that part unchanged and explain why in a final section
  "Review responses", one bullet per finding number.
- Keep existing IDs. Give new items new IDs; never renumber or reuse an ID.
- Keep the layout of the document.

Read the updated document to check your edits.
